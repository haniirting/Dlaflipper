# Multi RFID Switcher — Flipper Zero

Приложение для Flipper Zero: показывает список сохранённых LF RFID карт
(`/ext/lfrfid/*.rfid`) и позволяет переключаться между ними и запускать
эмуляцию выбранной одним нажатием.

## Возможности

- Сканирует папку `/ext/lfrfid/` на карте Flipper и строит список всех
  сохранённых карт (`.rfid` файлы)
- Выбор карты из списка кнопкой **OK** → запуск эмуляции
- Кнопка **Назад** во время эмуляции — остановка и возврат к списку,
  можно выбрать другую карту

## Требования

- Flipper Zero с прошивкой (официальная / Unleashed / RogueMaster)
- [ufbt](https://github.com/flipperdevices/flipperzero-ufbt) — micro Flipper
  Build Tool
- Python 3.8+ для установки ufbt

## Сборка и установка

```bash
# Установить ufbt (один раз)
pip install ufbt

# В папке проекта
ufbt          # сборка .fap
ufbt launch   # сборка + загрузка на подключённый по USB Flipper + запуск
```

Собранный файл приложения появится в `dist/multi_rfid.fap`.
Также можно скопировать его вручную на Flipper в папку `apps/Tools/`.

## Как подготовить карты для списка

Перед использованием приложения сохрани нужные карты через стандартное
приложение Flipper:

1. **125 kHz RFID** → **Read** → поднеси карту
2. **Save** → дай файлу имя (например, `School`)

Повтори для всех карт, которые хочешь переключать. Они появятся в списке
при следующем запуске Multi RFID Switcher.

## Известные ограничения / куда смотреть при доработке

- Текущая версия работает только с **LF RFID (125 kHz)** картами.
  Для NFC (Mifare Classic/Ultralight) нужна отдельная версия на базе
  `nfc_worker` API — структура похожая, но другие вызовы.
- Названия некоторых функций lfrfid API могут немного отличаться между
  официальной прошивкой, Unleashed и RogueMaster. Если сборка падает с
  ошибкой о неизвестной функции — проверь версию SDK (`ufbt vscode_dist`
  покажет актуальные заголовки) и поправь вызовы под неё.
- Иконка приложения (`fap_icon` в `application.fam`) требует файла
  `multi_rfid.png` 10×10 px, 1-bit. Если его нет — либо добавь свой,
  либо временно убери строку `fap_icon` из `application.fam`.
